# Mini Project 3

This project will be using Flask to deploy a small web app of your choice. The goal here is to come up with a small web application

## Getting Started

### Dependencies

```
pip install -r requirements.txt
```

### Executing program

```
python app.py
```

## Output

A locally hosted Flask web app that lets you search the NIST vulnerability database by keyword or CVE ID and displays the results with severity scores, descriptions, and references across multiple pages.
