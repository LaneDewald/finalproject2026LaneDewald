About This Project

Project Overview

This is my final project for INF601 – Advanced Programming with Python. The goal was to build a practical, multi-page web application using Flask and a real-world API. I chose to build a CVE Lookup Tool because cybersecurity is my major and being able to quickly look up vulnerability data is a genuinely useful skill.

The app uses the NIST National Vulnerability Database (NVD) REST API v2.0 to fetch real CVE data. Everything is free and no API key is required for basic queries, though NVD does have rate limits so the app includes basic error handling for that.

Features
  • Keyword & CVE ID Search – Query NVD by product name, technology, or exact CVE identifier
  • CVE Comparison Tool – Compare two CVEs side by side with a severity winner summary
  • Search History – Session-based history so you can re-run recent searches with one click
  • CVSS Severity Guide – An educational reference page explaining what scores mean
  • CVSS v3/v2 Support – Automatically uses the best available CVSS version for each CVE
  • Error Handling – Gracefully handles timeouts, bad IDs, and empty results
Tech Stack
  • Python 3.x
  • Flask – Web framework, routing, session management
  • Requests – HTTP library for API calls
  • Jinja2 – Templating (comes with Flask)
  • Bootstrap 5 – CSS framework for styling
  • NVD API v2.0 – Data source
